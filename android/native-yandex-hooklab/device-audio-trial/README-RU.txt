CELIKOM Android A1 — BETA28 (HONOR 50 / Android 13)
27.11.2026. Экспериментальная сборка для владельца. Не stable/OTA.

BETA27: FIRST_OPEN_DESCRIPTOR_LOST=NONE, FIRST_OPEN_CANDIDATE_ACCEPTED=ONE,
FIRST_OPEN_SETTER_MATCH=ONE, FIRST_OPEN_DEFERRED_ARM_CALLED=ONE.
Но BETA_OWNER_AUTO_START=FAILED, OWNER_ENABLED=NONE, OWNER_RESOLVE_REQUEST=NONE,
DEFERRED_ARM_NO_PENDING_APPROVED=ONE. Альтернативный источник не подключён.
Точная причина сбоя сессии из предыдущего TXT неизвестна.

BETA28: короткое нажатие CELIKOM сохраняет TXT; удержание открывает меню
проверки/входа CELIKOM. Ошибки конфигурации, сессии и активации различаются.
HTTP 401 при обновлении или активации требует повторного входа. Не повторяем
автоматически потенциально уже использованный refresh token после сбоя.
Вход только по собственной учётной записи CELIKOM. Не меняем авторизацию
Яндекса, сервер, каталог, подписанные разрешения, аудиомеханизм BETA27,
Windows, stable, OTA, исходные codecs.

Установить поверх BETA27, не удалять приложение и не очищать данные.
Если статус не ВКЛ, удержать CELIKOM: ... TXT, выбрать «Войти» при сбое
сессии или «Проверить» для повторной проверки. Дождаться ВКЛ.
Затем проверить Ramil / 10AGE — «Ау» (альбом 38902809, track 144530503),
00:43–00:54 и вторую песню. Обычным нажатием экспортировать TXT.
Успешная активация не доказывает реальную подмену; требуется звук и
полная цепочка OWNER_RESOLVE → GRANT_ADMITTED → DATASOURCE_ARMED → AUDIO_READ.
