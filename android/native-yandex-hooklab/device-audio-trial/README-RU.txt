CELIKOM Android A1 — Рамиль «Ау», BETA18 (HONOR 50 / Android 13)
26.11.2026. Тестовая версия исправляет переход от factory, возвращённой оригинальной Exo descriptor factory, к реальному RetryingBalancingDataSource. Метод создания выбирается только при единственном точном DataSource-return contract; результат связывается с descriptor по Java identity. Сохраняются исходный Player setter, поколение источника, Track+Album и прежние проверки grant/Range. Реальный эффект пока НЕ подтверждён прослушиванием.

1. Установить BETA18 поверх уже установленной BETA17. Приложение и данные не удалять.
2. Открыть CELIKOM/Yandex, дождаться входа.
3. Из альбома 38902809 включить трек 144530503 «Ау»: https://music.yandex.ru/album/38902809/track/144530503
4. Прослушать 00:43–00:54. Сообщить, слышна ли одобренная альтернатива №1.
5. Нажать «CELIKOM: … · TXT» и прислать TXT. Без ADB, кабелей, компьютера или второго телефона.

Не менялись server/grant/Range, оригинал Яндекса, стабильный Android и Windows. JVM, ARM13 и проверенная HTTPS-доставка APK не заменяют реальную акустическую проверку.
