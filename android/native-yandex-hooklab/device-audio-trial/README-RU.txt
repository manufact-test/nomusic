CELIKOM Android A1 — RAMIL' «АУ», BETA5 (HONOR 50 / Android 13)
Дата: 20.11.2026. Исправленная диагностическая сборка интерфейса, не стабильный релиз.

1. Установить APK поверх BETA4. Не удалять приложение, не очищать данные и не трогать оригинальную Яндекс.Музыку. Это сохраняет зашифрованную CELIKOM-сессию, если она была в предыдущей сборке.
2. Запустить CELIKOM/Yandex clone. Отдельной кнопки «Подключиться к BETA» больше нет: при старте приложение автоматически проверяет сохранённую CELIKOM-сессию и запрашивает активацию у CELIKOM. Учётная запись Яндекса не читается и не используется.
3. Вверху справа должна быть одна кнопка статуса/диагностики:
   - «CELIKOM: ВКЛ · TXT» — серверная CELIKOM-активация подтверждена;
   - «CELIKOM: ПРОВЕРКА · TXT» — запрос активации выполняется;
   - «CELIKOM: НЕТ СЕССИИ · TXT» — сохранённая CELIKOM-сессия не найдена;
   - «CELIKOM: НЕТ ДОСТУПА · TXT» — CELIKOM-сервер не выдал доступ;
   - «CELIKOM: СЕРВЕР · TXT» / «ОШИБКА» — запрос не завершился успешно.
   Нажатие на эту единственную кнопку сохраняет TXT в «Загрузки / CELIKOM A1». Никакой кнопки BETA/ручного подключения нет.
4. Открыть 10AGE, Ramil' — «Ау» (2019), ID 144530503: https://music.yandex.ru/album/38902809/track/144530503
5. Слушать участок 00:43–00:54. Сейчас проверяем только факт звучания альтернативной версии прямо в оригинальном ExoPlayer Яндекса. Pause/Resume, Seek, Next и MyWave пока не тестировать.
6. Если звучит цензурный оригинал, нажать единственную кнопку «CELIKOM: … · TXT» и прислать файл из «Загрузки / CELIKOM A1». Ничего не переустанавливать и данные не очищать.

В диагностике есть ограниченные счётчики связи publisher trackId → Track → tCa wrapper → оригинальный source/Exo DataSource, включая восстановление Fp0/RAa coroutine scopes. Счётчики показывают только NONE/ONE/FEW/MANY. URL, токены, пароли, учётные данные и аудиоданные не экспортируются.

CI подтверждает сборку и проверки кода, но не доказывает слышимую подмену. Финальное подтверждение — только реальный тест на HONOR 50.
