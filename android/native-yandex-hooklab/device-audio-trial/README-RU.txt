CELIKOM Android A1 — Рамиль «Ау», BETA13 (HONOR 50 / Android 13)
21.11.2026. Исправлена несовместимость с живым CELIKOM API v1: найденная одобренная запись возвращает signed session URL, но без двух новых полей approved/entitled. Android разрешает старый контракт только с подписанным сессионным билетом (sid), не принимает явный отказ, чужой Track или URL.

1. Установить поверх BETA12. Ничего не удалять и данные не очищать.
2. Открыть CELIKOM/Yandex. Доступ включается автоматически.
3. В альбоме 38902809 включить трек 144530503 «Ау»: https://music.yandex.ru/album/38902809/track/144530503
4. Прослушать 00:43–00:54 и проверить, слышна ли одобренная альтернатива №1.
5. Если играет оригинал, нажать «CELIKOM: … · TXT» и прислать TXT. Без ADB, кабелей и нового входа.

CI не доказывает звучание. Проверка реальной подмены — только на телефоне.
