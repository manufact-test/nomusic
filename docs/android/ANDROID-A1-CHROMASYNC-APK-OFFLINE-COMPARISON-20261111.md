## Critical package-coexistence caveat found in real uploaded manifest

Both outer ChromaSync clone and its nested `origin.apk` still declare **`com.yandex.preinstallsatellite.appmetrica.provider`** without a clone-specific authority suffix. The Android installer generally requires globally unique ContentProvider authorities, so the competitor binary's distinct package name **does not prove it can coexist with an unmodified original Yandex installation**. It may actually conflict with an official app declaring the same provider; no real on-device Android PackageManager test of this competitor alongside official app was performed. ChromaSync's public installation README explicitly cautions that uninstalling the original may be necessary. CELIKOM's own isolated 5+1 installation gate already addressed that authority collision structurally; removing that safeguard is NOT authorized. If someone requests testing ChromaSync directly, do not risk the owner's real official Yandex or ask to remove it.
