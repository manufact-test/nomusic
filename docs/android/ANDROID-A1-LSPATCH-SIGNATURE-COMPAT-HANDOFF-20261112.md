Статическое исследование: внешняя `app.chromasync.yamclone`, LSPatch metaloader stub, вложенный `assets/lspatch/origin.apk` (2025.10.4 #120.1rur, шестью DEX, своим подписанным именем пакета), внутренний `app.mywave.injector` модуль и **`sigBypassLevel=2`**. Полная конкурирующая внешняя APK в реальном ARM Android 13 **живёт 25/25 PID и foreground в течение 75 секунд**, извлечённая без оболочки копия — **падает**. Разница сразу **нескольких** компонентов: нельзя честно объявлять `level=2` единственной причиной успеха.

## Следующая реальная задача

1. **Восстановить точный источник для запуска проверки**, проверив, где уже в нашей приватной инфраструктуре сохранился **ровно pinned 2026 #170gpr**, либо реализовать **новый отдельно обозначенный** 2025 GPR эксперимент, используя уже загруженный приватный draft и соответствующие существующие инструменты; не ослаблять хеш-проверки и не публиковать двоичные файлы на открытый GitHub.
2. Запустить действительно нативный ARM13 A/B, получить **реальный статус MAIN PID + resumed Activity + 75 сек** для independently signed CELIKOM и контрольного issuer original, отдельно измерить влияние уровня LSPatch на одном и том же host.
3. Если действительно появится работающий native MAIN, следующим шагом внедрить **собственный**, без кода/секретов ChromaSync, модуль выбора source до decoder prepare, подключив существующий `android/native-audio-contract` B42. Сначала UI+startup и отсутствие двойного плеера, затем реальное аудио/пауза/seek/Next/MyWave. Не объявлять synthetic wire tests рабочим Android.
4. Оригинал на HONOR должен оставаться установленным. Пользователь имеет один HONOR 50 — не требовать второй телефон. Владелец требует **крупные самостоятельные проходы** без микроспрашиваний/отчётов, ручная проверка только при реально готовой сборке или неизбежной потребности.
