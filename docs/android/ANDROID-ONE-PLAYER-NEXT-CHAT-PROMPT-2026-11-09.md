# CELIKOM Android — стартовый текст следующего чата (09.11.2026)

Продолжаем `manufact-test/nomusic`. **Не начинай Android с нуля.** Рабочая ветка `experiment/android-native-yandex-fileinfo-hooklab-20261109`.

**Сначала:** `docs/android/ANDROID-NATIVE-CANONICAL-HANDOFF-2026-11-09.md`, `docs/android/NEXT-CHAT.md`, `docs/android/ANDROID-NATIVE-LSPATCH-EMULATOR-ROOT-CAUSE-2026-11-09.md`, `android/native-yandex-hooklab/README.md`.

**Цель владельца:** CELIKOM работает непосредственно в **нативном приложении Яндекс.Музыки**, пользователь входит только в Яндекс, **один родной плеер**. Никаких WebView, второго MediaPlayer, root, отключения Play Protect, фальшивой подписи, захвата OAuth/паролей, автоматического удаления или изменения официального Яндекса на HONOR.

**Уже сделано:** точный оригинальный `ru.yandex.music 2026.10.3 #170gpr / 24026531` и его подпись проверены; в реальном байткоде найден `FileInfoApi → FileInfoDto.urls/codec/key → sw7.y0/z0 → eed`. Написан минимальный **read-only** native libxposed модуль с хуками по точным сигнатурам, собирается. На CI LSPatch может временно упаковать пять подписанных APK-частей в отдельную модифицированную сборку с `sigbypass=0`, после проверки binaries удаляются. [Модуль PASS](https://github.com/manufact-test/nomusic/actions/runs/42611563341) · [Патч/ELF PASS](https://github.com/manufact-test/nomusic/actions/runs/42623602723).

**Ключевой блокер:** проверили контрольные запуски. Оригинальная #170gpr на Android11 x86+ARMv7 AVD **работает** [PASS](https://github.com/manufact-test/nomusic/actions/runs/42621833205). LSPatch с модулем **падает** до загрузки CELIKOM [NO-GO](https://github.com/manufact-test/nomusic/actions/runs/42622523007). LSPatch вообще **без** CELIKOM падает идентично [NO-GO](https://github.com/manufact-test/nomusic/actions/runs/42622723034). Android11 x86_64 тоже [NO-GO](https://github.com/manufact-test/nomusic/actions/runs/42624416091). Ошибка: `liblspatch.so` / `dlopen failed` / `UnsatisfiedLinkError`. Присутствие .so всех ABI, формат ELF, отсутствие сжатия и выравнивание 4096 подтверждены — это не «забытый файл». На Android13 x86_64 установка исходных ARMv7 библиотек не проходит. Это **не означает**, что LSPatch обязательно сломан на физическом ARM, но **на эмуляторах runtime нет**.

**Что делать дальше:** не гонять x86-эмуляторы по кругу и не переписывать модуль, который даже не успел запуститься. Подготовить **изолированный нативный ARM Android13+ тестовый стенд** (не HONOR владельца) с Play Protect ON и безопасной процедурой установки/отката; выяснить, как сделать его доступным без нарушения ограничений. Если такого стенда нет, честно сообщить блокер и предложить конкретный безопасный путь. При успешном запуске сначала доказать загрузку native хуков и `track+edition → FileInfoDto → eed → единственный декодер до prepare`; только после этого писать реальную замену разрешённого аудио с fail-open на оригинал и тестами pause/seek/next/random.

**ЗАПРЕТЫ:** не объявлять сборку работающим CELIKOM, не публиковать патченный Яндекс, не просить пароль Яндекса в CELIKOM, не ставить на основной HONOR, не трогать Test.50 (эталон), основную ветку, сервер или каталог. Пользователь разрешил подготовку **для отдельного тестового устройства**. Больше дела, меньше отчётов.
