# Первое сообщение для следующего рабочего чата — CELIKOM Android PLAN A

Привет! Продолжаем **CELIKOM Android** в существующем GitHub `manufact-test/nomusic`. Ты новый ведущий разработчик. **Ничего не начинай с нуля и не меняй продуктовую постановку самостоятельно.** Работай большими блоками, сохраняя независимые бэкапы и выполняя проверки.

**Актуальный ПЛАН А утверждён владельцем 10.11.2026:** собственное Android-приложение **CELIKOM** с **нашим** UI, подключением к **пользовательскому Яндекс-аккаунту**, каталогом/библиотекой/поиском/плейлистами/«Моей волной» из сервиса Яндекса и **одним** нашим управляемым проигрывателем. По trackId+edition приложение до начала воспроизведения выбирает **оригинальный разрешённый Yandex audio source** или **одобренную альтернативу CELIKOM** (только при действующей подписке/3-дневном trial). Никакого второго независимого игрока/эквалайзерной синхронизации. Это **НЕ WebView с оригинальным сайтом Яндекса**, **НЕ переподписанный APK Яндекса**, **НЕ companion рядом с отдельным официальным Яндексом** и **НЕ Media3 с каталогом только наших замен**. Проверить, что Яндекс действительно предоставляет разрешённый доступ к каталогу, радио и аудиопотокам для нашего клиента; OAuth Яндекс ID сам по себе этого не гарантирует.

**Ветка для НОВОГО плана А:** `feature/android-yandex-client-plan-a-20261110` (создана от сохранённой нативной разработки, пока документационная; новый Android client код не написан).

**Первый большой блок:** самостоятельно инвентаризируй собственные источники и официальный Яндекс OAuth/API; реализуй или чётко отсеки настоящий разрешённый путь `вход в собственный client → каталог/Моя волна/track ID → разрешённая оригинальная аудиодорожка`. Не трать неделю на синтетические proof/DEX. Без реального доступного Yandex audio source эта архитектура ещё не доказана: короткий GO/NO-GO и отчёт с причиной. После этого — один ExoPlayer и выбор оригинал/наша signed альтернатива *до play*, проверка в реальной безопасной Android среде. Не путать зелёный CI с услышанной музыкой.

**Безопасность обязательна:** никаких Яндекс-паролей в CELIKOM, никаких чужих client_id/token, свой зарегистрированный OAuth client/минимальные scopes, Android Keystore, без localStorage токенов, серверный trial 3 дня и подписка CELIKOM, recheck на каждую выдачу signed audio URL, ограничение host/redirect, отсутствие secrets в логах. Не обходить DRM, Play Protect или подписки Яндекса. Права/условия сервиса и лицензии перед продажей отдельно проверить.

**НЕ ТРОГАТЬ:** Windows, старые Android ветки, Test.50, оригинальный Яндекс на основном HONOR, расширение, production server/БД. Делать крупные самостоятельные блоки и приходить к владельцу только с серьёзным результатом, препятствием или настоящим APK для осмысленной проверки.
