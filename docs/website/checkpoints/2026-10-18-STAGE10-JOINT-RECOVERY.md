# CELIKOM website — контрольная точка v4.1 / 18.10.2026

**Состояние:** завершён большой технический блок безопасности Stage 9/подготовки Stage 10. Это НЕ формальная приёмка, не разрешение на production и не закрытие Stage 10. Реальная ветка `feature/api-range`, PR #6 оставлен открытым. Универсальная AI Site CMS разрабатывается в отдельном репозитории и в эту работу не входит.

## Что реально сделано после v4.0

1. **Общая CI починена без изменения утверждённого v10:** общий репозиторный линтер допускает отсутствие последней LF только для двух эталонных HTML при строгой проверке их исходного git-blob SHA; mysql service заменён на работающий образ. Это не глобальное исключение из правил линтинга.
2. **Offline репетиция раскладки на Hostinger:** `website/tests/Stage9OfflineDeploymentLayoutTest.py` копирует только public/app/database в одноразовую структуру, проверяет неизменность v10 CSS/JS и приватный запрет 404, для публичного сайта и CMS до выпуска обязателен 503/noindex.
3. **Release gate усилен:** `CmsReleaseGate.php` сверяет точное содержимое и права приватного owner token; пустые, изменённые, симлинк и произвольный PHP отклоняются. Никакого реального `release-approved.php` не создано.
4. **Репетиция файлового отката:** `Stage10FilesystemRollbackRehearsalTest.py` переставляет 3 дерева во временном домене и откатывает их после трёх принудительных прерываний; приватные файлы владельца и чужие сайты остаются целыми. **Это НЕ готовый live-rollback Hostinger**.
5. **Read-only выпускной аудит:** `CmsReleaseReadiness.php`, `check-release-readiness.php` подтверждают целостность v10, черновика, опубликованной редакции, одиночного активного владельца CMS; требуют правообладательски одобренное popup PNG с SHA256. Даже при положительных технических проверках `ready=false`: живые backups/rollback/согласие владельца отдельно обязательны.
6. **Полная зашифрованная резервная копия MySQL сайта:** `CmsFullDbBackup.php`, `backup-full-cms-db.php`; XChaCha20-Poly1305 secretstream, независимый случайный ключ из env, приватный файл `0600`, отсутствие открытого дампа на диске; включает `admin_users`, `audit_log`, ревизии, настройки и остальные таблицы. Test `Stage10FullDbBackupTest.php` восстанавливает в изолированный CI MySQL и отклоняет подделку, обрыв, неверный ключ.
7. **НОВЫЙ СОВМЕСТНЫЙ ОТКАТ/ВОССТАНОВЛЕНИЕ:** `CmsRecoveryPair.php` сопоставляет зашифрованный полный дамп с существующим `CmsBackup.php` (контент и бинарные приватные media), проверяя значения всех совпадающих строк/ревизии/размеры и MIME картинок, а не только количество. `Stage10JointRecoveryTest.php` после подтверждения пары разворачивает полную БД и приватное изображение в совершенно новое CI окружение, сверяет HTML опубликованной редакции, записи пользователей и audit. Проверка отклоняет подложный контент с пересчитанным SHA, неверный ключ и публично читаемый backup.

## Принципиальные ограничения

- **Production deploy workflow намеренно HARD DISABLED**: `.github/workflows/deploy-celikom-website.yml` содержит обязательный `&& false`; его прежняя выкладка `scp` прямо в живую директорию не имела безопасного server-side staging, атомарного переключения, автоматического отката/healthcheck/полного бэкапа. Не убирать блокировку только на основании зелёной CI или строки release-gate.
- **Два экспорта не являются атомарным бэкапом работающей БД.** `CmsRecoveryPair` обнаруживает расхождения четырёх пересекающихся таблиц; production-процесс должен обеспечить тишину записей / доказанный единый согласованный snapshot, а также включить приватные images. В текущем CI во время экспорта база не изменяется.
- Контентный архив `CmsBackup` хранит JSON+base64 медиа: он `0600`, но **сам по себе не зашифрован**, поэтому требует шифрования перед offsite передачей и защищённого хранения; независимая полная копия БД шифруется автоматически. Секрет полного бэкапа не хранить в репозитории/логах.
- Существующие `website/public/index.php` и `website/public/admin/index.php` до отдельного ручного подтверждения показывают 503/noindex. Миграции на настоящей базе не запускали. Отдельный Hostinger smoke/SSL/production DB/rights review ещё впереди.
- Изображение `/media/celikom-popup-approved.png` по-прежнему **не предоставлено/не подтверждено как разрешённое для публикации**. Заменять им макет случайным или взятым из исходников фото нельзя; без owner rights / privacy / визуальной валидации публикация блокируется.
- Исходники `website/app/Templates/site-v10.html`, `website/reference/v10/*`, оригинальные 5 CSS и 2 JS, `extension/`, `server/`, `android/` не менялись. PR #6 не сливать.
- Базовый продуктовый FAQ: trial 3 дня; плановая цена $2.99/мес без рабочей платёжки; **2%** за новую уникальную одобренную песню, максимум **20% в месяц**, лишнее переносится дальше; 3% только архивный тест.
