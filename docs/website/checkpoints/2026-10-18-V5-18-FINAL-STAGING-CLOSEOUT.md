## Когда владелец вернётся для публичного подключения

Не нужно начинать разработку с нуля. Продолжить с этих ссылок и актуального GitHub-кода. **Сначала спросить только постоянный домен и согласовать запуск; не выпускать сайт автоматически.** Контролируемая последовательность:

1. Выбрать основной домен/при необходимости www, подготовить DNS → Hostinger, действительный HTTPS, каноникал/редиректы.
2. Финализировать CTA установки (фактический статус распространения расширения), ссылки, контакты, поддержку, условия/политику конфиденциальности/cookie, фактические условия наград 2% за принятую песню с лимитом 20% в месяц (накопление сверх лимита — на следующий месяц) и прочие содержательные данные. Здесь требуется сверка с реально принятым функционалом расширения, а не предположения.
3. **До публичного размещения** согласовать права на публичное воспроизведение двух музыкальных фрагментов; загрузка владельцем и закрытый preview сами по себе не гарантируют право публичной раздачи.
4. Реальный Hostinger release-preflight: надёжный backup MySQL + приватных медиа; тест восстановления/отката, работоспособность PHP/SEO/админки, защита аутентификации, безопасный перевод закрытой CMS вместе с сайтом в публикацию. Инженерные Stage 10 CI-прототипы recovery НЕ заменяют подтверждённую репетицию на боевом Hostinger.
5. Только после явного согласия владельца и всех проверок — контролируемо снять HTTP Basic и разрешить production route; проверить десктоп/мобильную, FAQ/аудио, CTA и публикацию; наблюдать за ошибками и сохранить возможность rollback.

**Запреты на текущем этапе:** production workflow `.github/workflows/deploy-celikom-website.yml` содержит жёсткий `&& false`; не убирать без отдельного согласованного безопасного плана. Не создавать `website/RELEASE_READY` или `celikom-private/app/release-approved.php` сейчас. GitHub PR #6 не сливать. Не редактировать `extension/`, `server/`, `android/`, активную библиотеку и сам утверждённый HTML v10.

Будущая замена временной CMS отдельной универсальной **AI Site CMS** относится к другому репозиторию и **не является зависимостью** для публичного запуска CELIKOM. Не интегрировать её в CELIKOM самостоятельно, пока владелец не попросит.
