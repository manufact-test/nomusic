# CELIKOM website — инвентаризация инфраструктуры и доступов

> **Безопасность деплоя админки:** текущий `.github/workflows/deploy-celikom-website.yml` — предварительный сценарий для статического сайта. Он копирует `website/.` в `public_html`, поэтому **небезопасен для будущей PHP CMS**, если в `website/` появятся приватные файлы. До первого деплоя динамического сайта **обязательно** разделить `website/public/` и приватный `website/app/`/миграции/конфигурацию с публикацией последних вне web-root. Основное ТЗ: [MASTER-TZ.md](MASTER-TZ.md), §6.2–6.4. До этого workflow не запускать с приватным кодом или секретами.

Дата: 17.10.2026. Сведения о ресурсах и точках подключения **без приватных данных**.

> Репозиторий CELIKOM может быть публичным. Нельзя писать сюда пароли, приватные SSH-ключи, токены, cookie, файлы .env и секретные значения. Не помещать их ни в README, ни в коммиты, ни в задачи/чат.

## Статусы подключения
- GitHub connector в ChatGPT: подключён и разрешает коммиты.
- Прямой Hostinger SSH из ChatGPT: не предоставлен; подтверждён только вход владельца из локального терминала.
- Приватные SSH-ключи: хранятся локально у владельца и защищены в GitHub Secrets, недоступны для просмотра через обычный GitHub connector.
- Hostinger Connector как отдельное подключение: не подтверждён.
- На данный момент веб-сайт не опубликован нами: workflow есть, но `website/index.html` отсутствует; публикация не проверена.
