Ему нужен **РЕАЛЬНО ДОСТУПНЫЙ ПО URL сайт CELIKOM и работающая `/admin/`**, чтобы войти со своего компьютера и самому менять тексты, FAQ и изображения, сохранять, смотреть предпросмотр и публиковать. Приоритет №1 следующего чата — **добиться работающего закрытого веб-стенда на домене**, а не снова подготовить очередной технический пакет. Владелец пока НЕ дал явного разрешения менять Hostinger; сначала согласовать любые реальные изменения хостинга/домена/БД и только после разрешения выполнить их.

## Текущий реальный статус, не путать с «сайт запущен»

- По Master-ТЗ **10 этапов**. Этап 1 — принят, дизайн v10 этапа 2 — утверждён. Этапы **3–8 технически реализованы и проверены CI, но не приняты владельцем**. Этап **9 — небольшая CMS технически написана** и работает в изолированных тестах (авторизация, 87 текстовых полей, FAQ, приватные изображения, SEO, черновики, preview, публикация, история/откат). **Она НЕ развернута для владельца, он ни разу не входил в рабочую /admin/**. Этап **10 не закрыт:** отсутствует установленная, доступная по URL пара «сайт + CMS», затем нужны QA, ручные правки, legal/права/SSL и контролируемый общий релиз. Не обещать, что всё «готово», пока пользователь не сможет зайти по ссылкам и редактировать.
- Рабочая реализация находится в GitHub под `website/`. **На хостинге сайт/админка еще НЕ развёрнуты нами как рабочий пользовательский URL**. Действующие `/` и `/admin/` защищены от открытия до приёмки: HTTP 503/noindex. Скриншоты в GitHub Actions — лишь артефакт CI, **НЕ результат, который владелец просит**.
- Отдельный большой проект **AI Site CMS** существует **в другом репозитории**; не ждать его завершения и не переносить в CELIKOM. Нынешняя CMS — компактный редактор **одного** лендинга, без универсального билдера и multisite.
