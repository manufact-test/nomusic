НЕ объявлять Stage 9 или 10 официально принятыми.
- Реальный сайт и `/admin/` на production остаются **HTTP 503/noindex**. Hostinger/production ранее не тронуты. PR #6 открыт и не сливать. `.github/workflows/deploy-celikom-website.yml` содержит `&& false`; не включать без явного разрешения.
- Эталон сайта **v10, 5 исходных CSS + 2 JS**, дизайн, иллюстрации, адаптив и `website/reference/v10` не изменять. Не трогать `extension/`, `server/`, `android/` и независимую AI Site CMS.

## ЧТО ДЕЛАТЬ В СЛЕДУЮЩЕМ ЧАТЕ — ТОЛЬКО ПРАКТИЧЕСКАЯ ПРОДУКТОВАЯ РАБОТА

1. Посмотреть отзыв владельца по готовому визуальному пакету, составить короткий конкретный перечень интерфейсных правок сайта и CMS. Если ещё не смотрел — помочь скачать Artifact, не повторять сложный аудит.
2. Главная следующая задача — **закрытый интерактивный staging** текущего сайта и его маленькой CMS. Владелец должен сам открыть страницу и `/admin/` в браузере, войти, изменить H1/CTA или FAQ, сохранить draft, посмотреть preview, опубликовать внутри staging, проверить возврат. Использовать отдельно выделенную тестовую MySQL, приватные media, HTTPS, дополнительный HTTP Basic Auth или другой надёжный login gate, noindex. **Не соединять с существующим production и не менять Hostinger/домены/БД без отдельного явного согласия владельца.** Сначала подготовить минимальную конфигурацию и получить разрешение.
3. По полученным замечаниям отредактировать то, что реально не нравится. Сайт должен быть понятным в использовании, минимальная CMS — быстро редактировать тексты/FAQ/изображения без GitHub; **не пересоздавать визуальный v10**.
4. Затем выполнить заключительные права/публичную popup PNG, тексты/ссылки/legal, SSL, бэкап/rollback с использованием уже написанных проверенных механизмов и возможностей Hostinger по ситуации, операторское согласие, **единый запуск** сайта+админки. Не проводить очередные новые CI-only SQL generation/KMS/fsync/offsite исследования без явного реального блокера.
5. **Документировать только после крупного блока или по просьбе**, не после каждого маленького изменения.
