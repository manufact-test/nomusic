# CELIKOM — Brand Guide v1.0 (дизайн-основа)

Дата: 17.10.2026. Источник решений: согласование владельца в чате о сайте CELIKOM.

**Статус:** утверждены общий характер, палитра, шрифт Manrope и мягкая концепция логотипа №2. Это рабочая дизайн-основа для начала арт-дирекшена. Векторизация знака и надписи выполнена как воспроизведение выбранной концепции; допускается оптическая доводка без смены стиля. Окончательные тексты лендинга, юридические обещания и статус публичной установки проходят отдельную приёмку.

## 1. Суть бренда

CELIKOM помогает вернуть **то самое знакомое звучание** любимых песен в поддерживаемом веб-плеере при наличии нужной проверенной версии. Не позиционировать как новый стриминговый сервис, не обещать любой трек или готовую Android/iOS-версию.

**Характер:** небольшой независимый проект разработчиков, просто, дружелюбно, уверенно, без «корпоративной легенды», без превосходных степеней и риторики «музыкальной революции».

**Рабочий Hero (контент на проверку):** «Те самые песни. То самое звучание». Подзаголовок обязан честно пояснять зависимость от каталога проверенных версий.

## 2. Палитра — утверждена

| Назначение | HEX | Использование |
|---|---|---|
| Основной тёмный | `#0B1013` | Заголовки, тёмные секции, знак на мятном |
| Основной мятный | `#66E0BF` | Активные элементы, фон главной кнопки, акценты |
| Светлый фон | `#F7F8F4` | Основная поверхность сайта |

Технические вспомогательные тона — **не самостоятельные фирменные цвета**, могут корректироваться по контрасту: `#556368` (вторичный текст), `#DCE8E3` (границы), `#14594D` (контрастные текстовые ссылки), белый (`#FFFFFF`), и дополнительный мягкий лайм `#DFFB97` (не использовать без явной дизайнерской необходимости). Не ставить мятный мелкий текст на белом.

```css
:root {
  --celikom-ink: #0B1013;
  --celikom-mint: #66E0BF;
  --celikom-paper: #F7F8F4;
  --celikom-text-muted: #556368;
  --celikom-border: #DCE8E3;
  --celikom-link: #14594D;
}
```

## 3. Типографика — утверждена

**Manrope**, кириллица, варианты 400 / 500 / 600 / 700 / 800; рабочий шрифт всего сайта. Заголовки: 700–800, с компактным межбуквенным расстоянием (не ломать русскую читаемость), основной текст 400–500, кнопки 700–800. Рекомендуемый шаг высоты строк для абзацев 1.6–1.85. В релизе проверить лицензию шрифта и, по возможности, использовать локальный WOFF2 с preload; в превью допустим Google Fonts.

## 4. Система знака — выбран вариант 2 («мягкий»)

Текущий код расширения `extension/scripts/build-icons.mjs` использует округлую букву C и состояния gray/green. **Утверждён внешний образ №2:** максимально мягкая C со скруглёнными окончаниями на графитовом скруглённом квадрате, рядом слово **CELIKOM** в плотном Manrope. Никаких острых рубленых граней, декоративных 3D-теней или незнакомой эмблемы.

Референс-реализация (векторная):
- `assets/celikom-mark.svg` — квадратная бренд-иконка;
- `assets/celikom-lockup.svg` — горизонтальная композиция.

Эти SVG предназначены для дизайна сайта. Они **не меняют иконки работающего расширения** и требуют проверки верстальщиком с загруженным Manrope, а также теста favicon в размерах 16/32px.

## 5. Визуальный язык и отступы

- Основной светлый фон с воздухом; мятный акцент дозированно; отдельные тёмные секции.
- Контейнер ~1240px, адаптивное уменьшение внутренних отступов: desktop ~44px, mobile ~18px. Сначала читаемость, потом украшения.
- Карточки преимущественно цельные светлые поверхности, радиусы ~20–30px, спокойные тени без стекла.
- Графические звуковые мотивы — декоративные; они **не изображают интерфейс музыкальной платформы**.
- В продукто-демонстрации **только реальный CELIKOM popup**: Повторить, Стоп, Вернуть оригинал, Загрузить версию, Предложить песню, статус аккаунта. Никаких выдуманных селекторов Acoustic/Live/Remix.
- `prefers-reduced-motion` и `:focus-visible` обязательны.

## 6. Выпуск и безопасность

Сайт и небольшая CMS выпускаются только **совместно** после тестирования. Текущий `.github/workflows/deploy-celikom-website.yml` небезопасен для приватных каталогов админки; до первого деплоя переделать сценарий. Не триггерить `website/**` при разработке локальных концептов. Не затрагивать `extension/`, `server/`, `android/`, PR #6. Не публиковать в публичном репозитории приватные изображения, данные аккаунта, токены и конфигурацию.
