# CELIKOM — корректировка админки, 11.10.2026

Владелец подтвердил работу popup при другой активной вкладке и наличие этапа 13. После просмотра двух скриншотов попросил убрать три отдельные полосы меню, исправить отступы формы инцидента и объяснить назначение команд.

Изменена только админка: один responsive nav с доступными по роли и feature flags разделами, перенос пунктов на узком экране. Сохранены routes, CSRF, права owner/moderator/viewer и действующие flags. Причина сбоя — textarea с подписью над полем; кнопка на следующей строке; отдельные отступы начала/завершения, мобильные кнопки на полную ширину.

Сервер 0.4.23; установленный клиент 0.4.22 остаётся актуальным. Новый клиентский ZIP не нужен. Миграций и изменений trial, ledger, наград, аудио, credentials нет. Не активировать billing/referrals и не объявлять реальный incident ради проверки UI.

Назначение раздела: owner объявляет подтверждённый общий сбой Yandex integration, подмена приостанавливается у всех клиентов, оригинал остаётся доступен, время действующего доступа сохраняется. После восстановления owner завершает incident, точное время компенсируется без удвоения пересечений. Локальный лаг одного пользователя не является основанием для глобального incident. Start/resolve уже проверены в disposable MySQL/MariaDB; для текущей ручной UI приёмки кнопки нажимать не требуется.

Проверки: единое меню для owner и отсутствие закрытых разделов у moderator; native Chromium на desktop/tablet/mobile проверяет видимость ссылок, единственный active tab и реальные зазоры текста/поля/кнопки. Прежние функциональные тесты расширения и backend сохраняются.

PR #6 OPEN/unmerged; Issue #7 OPEN, исходная причина зависания Yandex пока не подтверждена. Этапы 11/12 и коммерческие зависимости 13 остаются частичными; реальной оплаты нет. Предыдущие checkpoint документы исторические; актуальное продолжение — эта запись и STAGE13-2026-10-11.md.
