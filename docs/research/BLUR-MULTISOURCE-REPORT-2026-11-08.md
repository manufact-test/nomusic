# CELIKOM — поиск MP3 в дополнительных источниках, 08.11.2026

## Результат

Сверено **несколько публичных архивов и 11 форков** исходного каталога, проверены отдельные ссылки и аудиофайлы в изолированных GitHub Actions. В production не вносились изменения.

- **48 уникальных записей-кандидатов** с читаемым исполнителем/названием, файл MP3 прошёл MIME, SHA256, Git blob там, где доступен, ffprobe и CELIKOM Mp3Inspector. **Это не одобрение импорта**: ID3/названия сообщества не доказывают соответствие Track ID и не доказывают авторские права.
- **30 проблемных случаев для ручного разбора:** 18 HTTP 404, 3 файла WebM вместо MP3, 8 MP3 с отсутствующими/нечитаемыми тегами, 1 побайтовый дубликат аудио между Track ID 149360077 и 149665384. Из пары дубликатов в кандидатах оставлен ID 149665384; второй отправлен на сверку.
- Технически исправных MP3 исследовано **58** (14 YM Liberty, 17 независимые fork-файлы, 27 из старого исходного каталога). Один из 27 (`50400505`) уже **есть в production**, исключён. После исключения дубля остаются **56 потенциально уникальных файлов** на 57 отсутствующих Yandex Track ID; у 8 пока отсутствуют читаемые метаданные.
- Дополнительно проверены 29 HF-зеркал старых 138 забракованных записей. Все **29 имеют идентичные Git blobs** исходным проблемным файлам — восстановлений нет; старый список 138 не дублируем.
- **0 подтверждённых прав**, **0 подтверждённых независимо соответствий Track ID**, **0 созданных записей в production**.
