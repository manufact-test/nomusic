- Источник: `Hazzz895/FckCensorData` на неизменяемом pinned commit `10187b7af56f311fe141a3c9b75483798bf0f589`. Каждый файл закреплён Git blob SHA1, размером и измеренной длительностью.
- Точный неизменяемый состав **200 Track ID**: [tools/blur-batch600/fixed-plan600.json](../../tools/blur-batch600/fixed-plan600.json). Перезапуск импортёра повторяет только эти ID. Новых кандидатов после частичного успеха не выбирает.

- Изоляция: только новая ветка `feature/blur-batch600-20261108` на базе предыдущей feature-ветки. Старые `main`, Android, Windows, browser extension и серверная админка не изменялись.
