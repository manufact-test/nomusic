# CELIKOM — исследование второго источника YM Liberty, 08.11.2026

**Никаких загрузок в CELIKOM или изменений production.**

Исследовано: [YM Liberty DB](https://github.com/gagayhhad-tech/ym-liberty-db) + [YMliberty Hugging Face](https://huggingface.co/datasets/naloz/YMliberty).

## Что реально найдено

1. В публичном list.json YM Liberty — **1508 Track ID**. Из них **33 отсутствовали в исходном дереве FckCensorData** (1526 исходных файлов).
2. [Read-only сравнение с production](https://github.com/manufact-test/nomusic/actions/runs/42520424778): из 33 — **1 ID уже в CELIKOM** (`68070362`), **32 отсутствуют**. Ни заявок, ни tombstones среди этих 33.
3. [Проверка ссылок без скачивания аудио](https://github.com/manufact-test/nomusic/actions/runs/42520543959): **14 ссылок HTTP 200**, **18 дают HTTP 404**.
4. [Независимая техническая проверка 14 временно скачанных файлов](https://github.com/manufact-test/nomusic/actions/runs/42520675747): **14/14 настоящие MP3**, совпали заявленные размеры, SHA256 рассчитан, ffprobe+Mp3Inspector прошли, 0 ошибок, 0 production-записей.
5. Точные Track ID, ссылки источника, размеры, SHA256, длительность и ID3: `tools/blur-research/ym-liberty-14-verified.json`. Совокупный размер **109777942 байт**.

## Ограничения перед возможным импортом

- 14 — это **технически валидные источники**, не 14 новых активных версий. Они не загружены в CELIKOM.
- Теги MP3 и подписи сообщества **не подтверждают соответствие Yandex Track ID**. Необходимо сверить музыкальную запись с нужным треком.
- Право на копирование, хранение и распространение аудио **не подтверждено**, факт публикации на GitHub/HuggingFace права не предоставляет.
- 18 ссылок 404 не пытаться автоматически заменять похожими песнями и не заявлять об успешном импорте.
- Оставить работу на изолированной ветке, не трогать main, Android, Windows или расширение.

## Путь продолжения

Получить подтверждение прав и правильной привязки 14 IDs, после чего можно использовать существующий проверенный конвейер с фиксированным SHA256, 14 pending и независимым production-аудитом. Другие проекты (FkCensor, YandexMusicClient, WinYandex) в основном повторяют FckCensorData, так что нельзя считать их независимыми источниками аудио без конкретного другого каталога.
