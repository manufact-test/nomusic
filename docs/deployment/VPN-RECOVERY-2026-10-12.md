# Сеть/VPN: регистрация и музыка0.4.33

Владелец: Urban VPN, регистрация второго аккаунта завершается общей ошибкой, Яндекс начинает выдавать ошибки playback. Присланный отчёт0.4.32: enabledfalse,STOPPED,bridgehealthy,activation0,restore0,guardfalse,playernull; страница search, utility data audio15ms и advideo. Отчёт не содержит результата регистрации/HTTP и не доказывает rootcauseVPN или ошибку подмены. В этом состоянии CELIKOM не запускал альтернативу/не удерживал оригинал. Пассивные hooks остаются, поэтому влияние расширения на Яндекс целиком не объявляется исключённым; автоматические тесты проверяют noninterference fetch/XHR.

Подтверждённые проблемы кода: клиент auth deadline8s против SMTP deadline120s; после INSERT users и потери ответа повторная register возвращала409 даже с исходным паролем и неподтверждённой почтой. Новый срок20s для действий с письмом, SMTP connect4/read2/budget12s. Повторная register с исходным паролем для active/unverified возвращает verification_required; не создаёт сессию/дубликат и не меняет привязку referral. Verified/wrong-password/account-disabled остаются409. Throttle/verification сохраняются, POST не повторяется автоматически.

Теперь network/timeout/HTML edgeblock различаются; bounded8 network diagnostic содержит только operation/method/status/result/elapsed/time, безemail/token/password/headers/URLquery/IP. HTML401/403/429 не объявляется отказом аккаунта; JSON403 остаётся deny. При recovery resolve cache/config обновляются; HTTP HTMLedgeblock аудио возвращает original и делает ограниченный retry с новой авторизацией. Не выполняется обход блокировок, certificate/CORS/origin проверки не ослабляются. Внешняя недоступность Hostinger/Яндекс/маршрутаVPN остаётся внешним ограничением; приложение не может гарантировать работоспособность сервиса через любой VPN.

Проверки в disposableDB, без регистрации реального второго аккаунта и реальных писем. Владелец затем повторяет signup с теми же данными0.4.33; при ошибке нужна network diagnostics. Для Яндекса сравнить тот же трек/VPN с отключённым расширением; если сам Яндекс не создаёт player и безCELIKOM, исправление подмены не устранит этот сбой. Android и обращениеGoogle остановлены по инструкции владельца; appeal не подан.
