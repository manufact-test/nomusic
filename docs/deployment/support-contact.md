# Техподдержка — правки по ручной проверке 12.10.2026

Владелец подтвердил: обращение дошло в админку, ответ дошёл на email аккаунта. Оформление и скорость требуют повторной проверки версии 0.4.31.

Форма: «Опишите проблему», поле, «Отправить», видимое «Сообщение отправлено». Копирование, технические пояснения и переписка из popup убраны. Клиент отправляет только введённый текст. Раздел разработчика скрыт. Админка: «Посмотреть», текст сообщения без технической обёртки, «Отправить», отступы; технические SMTP статусы не выводятся. Исторические сообщения хранятся без изменения, старая автоматически добавленная обёртка убирается только при отображении.

Письмо: ответ, «С уважением, команда CELIKOM», предложение обратиться через форму CELIKOM. Импорт входящих email не добавляется. Почта регистрации и получатель копии сохранены.

В FastCGI/LiteSpeed SMTP выполняется после завершения HTTP ответа. В других runtime остаётся синхронный fallback. Сохранение в БД, UUID/лимиты/CSRF/RBAC и однократный mail claim сохранены. При падении процесса до отправки pending сохраняется, автоматического повторения неопределённой отправки нет. Проверки используют только disposable DB и mail sink. Android в эту правку не входит.
