# Контакт техподдержки CELIKOM

0.4.29 содержит независимый от входа/incident popup раздел. Copy работает без настроенного адреса и без API; mail draft открывает почтовое приложение только по нажатию пользователя. Не выполняется автоматическая отправка. В обращении разрешены description<=2000/version/phase/track ID/controller-present; account/session/token/full diagnostics/URLs не сериализуются.

Владелец должен назвать и подтвердить mailbox поддержки. Пока адрес не указан, контакт пустой и email-кнопка отключена. Сборка принимает CELIKOM_SUPPORT_EMAIL, валидирует адрес без URI/control injection; упаковка не содержит предполагаемого email. Изолированная fixture team@example.org — только тест.

После подтверждения адреса пересобрать один полный клиент с прежним CELIKOM_API_BASE_URL. Переход на централизованную редактируемую owner contact config остаётся возможным; текущая поставка не выдаётся за уже работающую почтовую поддержку. Support для финального Android переносится в общий shell после определения native playback, адрес не выдумывать.
