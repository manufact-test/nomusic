## Changes — one combined Windows 0.24.19 EXE, no live PHP modifications
1. **Support W70 retained:** `DiagnosticLog.ExportSupportSnapshot` automatically attaches a bounded, allowlisted, token-free report upon explicit send for both general (`diagnostics`) and song (`report.diagnostics.windows`) tickets. The UI remains unchanged; technical buttons are staff-only. The current production PHP/admin supports these fields and provides owner/moderator-only **Скачать диагностику JSON**. No extra visible JSON/details. Browser/Android unchanged.
2. **Fix transient entitlement drops:** one short, bounded retry of GET entitlement after transport timeout or temporary 429/5xx, without replaying writes or weakening access control. If unavailable after retry, **immediately fail closed** (disable local bridge). A 15-second pulse continues only when the bridge was automatically suspended due to transient network trouble. Auto-resume **only** after a fresh, authenticated `PlaybackEntitlement.Allowed` result, verified same-account session and active matching native module; never from cached expiry, server 401/403, service incident, expired access, logout or account switch.
3. Manual **Стоп** (compact and legacy UI, tray), new explicit Start, login, logout and close cancel any pending auto-resume. UI distinguishes `Нет связи` from intentional `Выключен`; the Stop button remains usable to cancel the pending recovery.
4. **Better support report for intermittent issues:** 15-minute/64-event limit retained, but 600 frequent local state polls cannot drown out prior errors; reserve up to 24 incident/entitlement transitions plus 40 other contextual events, ordered in time, with the same strict allowlist. Raw logs, URLs, account data, signed audio links, password, token, path and exception text still excluded. The existing full owner TXT export is unchanged.
5. All W69 **uninstall saved-login checkbox**, existing AppId, official Yandex signatures, source toggle, original restoration, WinForms styling and native module retained. New app/native version **0.24.19**.
