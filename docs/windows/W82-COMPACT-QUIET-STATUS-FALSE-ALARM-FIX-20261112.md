# W82 — убраны ложные тревоги и сломанное оформление Windows CELIKOM (12.11.2026)

## Причина жалоб владельца
После W81 0.24.27 пользователь на реально играющей музыке увидел одновременно:
- большой красный `Нет ответа от модуля Яндекса. Проверь соединение`;
- большой и мелкий жёлтый `Подмена передана проигрывателю. Фактический звук ещё не подтверждён`;
- пунктирный прямоугольник фокуса вокруг кнопок, включая `Загрузить версию`;
- большой `Проверяем пробный период или подписку…`, который не нужен пользователю.

Системная причина красного: `w23/host.cjs` отправляет `/v1/heartbeat` только **при изменении** текущего track/status/metadata, а не периодически на каждой итерации. Поэтому W81 введённая в `CompactPopup.cs` проверка `lastHeartbeat > 30s` ложно превращала долгую нормальную песню в падение модуля. Жёлтый: `NATIVE_MAPPING_ACCEPTED` в renderer означает `SOURCE_MAPPING_RETURNED_NOT_AUDIO_VERIFIED`, а не доказанный плохой звук; W81 ошибочно показывал это как предупреждение.

## Изменения W82
- `PopupButton.cs`: убраны ручные пунктирные прямоугольники фокуса; геометрия, палитра и клики оставлены без изменений.
- `CompactPopup.cs`: **единственный большой текст** появляется только при `_compactStarting && _bridge.Enabled`: `Идёт загрузка Яндекс.Музыки…`. Нет больших технических сообщений, проверки подписки или красно-жёлтых статусов при музыке. Вся диагностика — исключительно в одной маленькой строке под песней.
- `UserFacingPlaybackHealth.cs`: убрана придуманная W81 эвристика по давности transition-only heartbeat. Воспроизводимая нормальная `NATIVE_MAPPING_ACCEPTED`, `NATIVE_CONNECTED`, `NATIVE_RECOVERING` и `RESOLVING` не считаются ошибкой. Реальные явно заявленные `NATIVE_SOURCE_FAILED` и `HOST_ERROR` остаются различимы, красным только **в малой строке**.
- `CompactPopup.cs`: при подтверждённой нативной передаче версии CELIKOM восстановлена простая привычная зелёная строка `Подмена активна · версия CELIKOM`. Если статус `ORIGINAL` при существующей approved версии — строка нейтральная, не зелёная: `Играет оригинал. Версия CELIKOM доступна.`.
- Цвета только существующие фирменные `Accent`, `Secondary` и `Danger`, жёлтый `#FFE1A1` в статусах убран.
- Модуль воспроизведения `windows-companion/w23` не менялся вообще. Подписка и доступ по-прежнему проверяются на сервере при Start, только не выводятся большим текстом.
- Исправлено именно ложное отображение, **не доказан реальный аудио-аудит**. Требование независимого надёжного подтверждения реального используемого источника и корректного liveness вынесено в [issue #52](https://github.com/manufact-test/nomusic/issues/52) без ложных обещаний.
