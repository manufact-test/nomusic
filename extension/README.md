# CELIKOM — браузерное расширение

Актуальная инфраструктура: https://api.celikom.com. Основная ветка — main.
Подробности переезда: docs/migration/CELIKOM-NEXT-CHAT-START-2026-11-23.md,
последние разделы от 25.11.2026 имеют приоритет над историческими записями.

## Сборка и получение

Node.js 24+, npm ci, затем npm run test:extension и npm run build:extension.
Новый адрес используется по умолчанию; явно указанные Hostinger origins отклоняются.
Loopback и отдельные HTTPS fixture origins остаются для тестов. Штатный workflow
.github/workflows/extension-build.yml собирает main на изолированном Floki runner,
проверяет API origin/host permissions/хеши и сохраняет ZIP с receipt в приватный spool.
Spool не является релизом и не обслуживается веб-сервером. Отдельный защищённый
административный шаг независимо сверяет хеш и архив до копирования в закрытое
релизное хранилище. Секреты и доступ к production не передаются сборочному runner.

Старый hostinger-extension-private.yml выведен из сборки; он больше не создаёт
пакеты для старого API. Hostinger сохраняется для отката инфраструктуры.

## Обновление установленной распакованной версии

1. Скачать проверенный полный ZIP и распаковать его.
2. Заменить содержимое прежней папки CELIKOM. Сохранить ту же папку/установку,
   чтобы не потерять локальную сессию. Не удалять расширение ради обновления.
3. В chrome://extensions (или brave://extensions) нажать обновление/перезагрузку
   установленного CELIKOM, затем один раз перезагрузить вкладку Яндекс Музыки.
4. Если новая сборка просит авторизацию — войти в существующий аккаунт.
   Учётные записи перенесены; новая регистрация или новый пробный период не нужны.

ZIP не является механизмом автоматического обновления распакованного расширения.
Нельзя обещать, что кнопка обновления скачает код с сайта: она перезагружает локальные
файлы. Обычное автоматическое распространение Chrome/Windows требует отдельного
выпуска через Chrome Web Store; managed/self-hosted установка — отдельный процесс.
Неподтверждённый update_url в manifest не добавляется. См. официальные ограничения:
https://developer.chrome.com/docs/extensions/how-to/distribute

## Границы изменения

Версия 0.4.79 сохраняет playback из актуального main 0.4.73: меняются конфигурация
сборки, понятные причины отказа Start, версия и проверки миграции. Никакой новой
архитектуры подмены, MediaSource live-join или переноса Android/Windows кода.
Работа музыки на реальном компьютере подтверждается владельцем отдельно от тестов.

## Кандидат 0.4.90 — непрерывный старт и подключение посреди песни

Разбираются две проблемы 0.4.89: позднее разрешение выбранного трека до появления native audio element и переключение на подмену до завершения mid-song seek. Дополнительно временный `awaiting-track-refresh` больше не должен сбрасывать замену, если прежний native resource подтверждён теми же media ID, resource revision и длительностью, а видимые title/artist не изменились. Подробности и границы проверки: `docs/handoff/CELIKOM-EXTENSION-090-AUDIO-CONTINUITY-20261126.md`.

0.4.90 — кандидат владельца, не принятая версия. Не публиковать клиентам и не менять owner promotion manifest до прохождения Floki/Chromium проверок и прослушивания владельцем.

## Кандидат 0.4.91 — продолжение проверки в Work

Исправлены ложный сброс по остановке часов при временно отсутствующих метаданных,
игнорирование Stop в этом состоянии и пропуск подготовки позиции при перемотке
в первые секунды во время загрузки. 440 тестов, сборка, манифест и проверка
безопасности прошли. Установка расширения в браузер Work заблокирована политикой;
реальное прослушивание и выдача через защищённый канал сайта ещё не подтверждены.
Подробности: `docs/handoff/CELIKOM-EXTENSION-091-WORK-VALIDATION-20261126.md`.

## Кандидат 0.4.92 — восстановление загрузки MP3 без сброса буфера

После краткого обрыва запроса или чтения ответа MP3 повторяется тот же подписанный
диапазон, сохраняя декодер и уже загруженное аудио. Исчерпанный сетевой сбой тела
ответа больше не превращается в общую ошибку, блокирующую автоматическое восстановление.
449 тестов, сборка, манифест и проверка безопасности прошли; реальное прослушивание
проверяется владельцем отдельно. Расширение общей диагностики остаётся отложенным.
Подробности: `docs/handoff/CELIKOM-EXTENSION-092-STREAM-RECOVERY-20261127.md`.
