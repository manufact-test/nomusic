CELIKOM — проверка ID песни

Диагностическая версия для проверки ссылки на текущую песню в Яндекс Музыке.

  1. Установите официальный клиент F-Droid.
  2. Добавьте тестовый репозиторий CELIKOM с помощью кнопки ниже. Если браузер не открыл F-Droid, нажмите «Скопировать адрес» ниже и добавьте его вручную в настройках F-Droid → Репозитории → +.
  3. Найдите в F-Droid «CELIKOM — проверка ID» и установите приложение из F-Droid.
Добавить репозиторий в F-Droid

Ссылка для добавления вручную:

Адрес нужно вставить внутри F-Droid: Настройки → Репозитории → +. Открытие адреса в браузере само по себе не добавляет репозиторий.

Проверка песни

  1. Включите песню в Яндекс Музыке и откройте её полный плеер.
  2. Откройте «CELIKOM — проверка ID» по значку приложения.
  3. Нажмите «1. Разрешить тест кнопок Яндекса» и включите службу для этого приложения.
  4. Нажмите «2. Подключиться к плееру», дождитесь данных песни, затем «3. Запустить тест и открыть Яндекс».
  5. Если появилось меню отправки, выберите «CELIKOM — проверка ID». Затем нажмите «Скопировать отчёт» и пришлите его.

Это собственный тестовый репозиторий CELIKOM, не каталог приложений, проверенных командой F-Droid. Приложение требует явного разрешения специальных возможностей для одной ограниченной попытки нажать меню песни и «Поделиться» в видимом окне Яндекс Музыки.

Если установка заблокирована, завершите эту проверку и пришлите текст сообщения. Установка и получение ID на HONOR пока не подтверждены.
