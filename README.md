# Development workspace

Служебный репозиторий разработки.

## Требования

- Node.js 24 или новее.
- npm 11 или новее.
- PHP 8.3 и Composer 2 — для серверных проверок.
- `zip` — для упаковки сборок.

## Локальные проверки

```bash
npm ci
npm run ci
```

Сборки размещаются в каталогах `dist/` соответствующих модулей.

Для локального серверного окружения:

```bash
composer --working-dir=server install
composer --working-dir=server test
php -S 127.0.0.1:8080 -t server/public
```

## Работа с репозиторием

- Документация и инструкции по отдельным направлениям находятся в `docs/`.
- `windows-companion/` — исходный код существующего приложения CELIKOM Windows.
- `main` — единственная каноническая производственная линия; `backup/*` — точные точки отката. Рабочие `experiment/*` и `qa/*` ветки для развития продукта не используются.
- Секреты, пользовательские файлы и персональные данные в Git не добавляются.
- Для выпуска действуют ограничения, зафиксированные в документации проекта.
